Editor degli sticker: crea i tuoi sticker

Leggi l'annuncio originale in Inglese

A partire da oggi, chiunque può creare rapidamente sticker e interi set di sticker usando un nuovo potente editor, senza uscire da Telegram.

Crea uno sticker

Prendi una qualsiasi foto e aggiungi testo, disegni o una miriade di sticker animati, emoji e GIF presenti sulla piattaforma. Trasformare i gatti in arte grafica non è mai stato così facile nella storia dell'umanità (e dei gatti).

Basta un solo tocco per ritagliare oggetti e rimuovere lo sfondo. Puoi cancellare e ripristinare manualmente parti della foto o aggiungere un contorno, per ottenere il classico aspetto di uno sticker.

Per iniziare a creare sticker, apri il pannello degli sticker dal campo di scrittura in qualsiasi chat, quindi tocca il pulsante (+).

Aggiungilo a un set

Quando hai finito, invia semplicemente lo sticker oppure crea un set di sticker in modo che gli amici possano riutilizzare le tue creazioni nelle loro chat.

Per aggiungere uno sticker a un set, scegli le emoji che descrivono la sua emozione. Telegram utilizzerà anche l'AI per suggerirti le emoji in base alla tua immagine, come un gatto, un cane o un'auto.

Su Telegram, le emoji fungono da scorciatoia per gli sticker. Quando digiti un'emoji in una chat, Telegram mostra automaticamente gli sticker corrispondenti che puoi inviare.

Espandi i tuoi set

Dal 2015, milioni di artisti e creatori di meme hanno usato la piattaforma aperta di Telegram per condividere le loro creazioni.

Puoi aggiungere qualsiasi sticker esistente ai tuoi set personalizzati. Ad esempio, per riunire tutti i tuoi preferiti in un unico set o per creare collezioni a tema.

Condividi i tuoi set

Per condividere i tuoi set di sticker, basta inviare a qualcuno uno degli sticker. I destinatari potranno toccarlo per aggiungere l'intero set. Ogni set ha anche il suo link univoco t.me.

Con questo aggiornamento, abbiamo aggiunto le anteprime dei link per tutti i set di sticker ed emoji.

Questo mese annunceremo altre 16 nuove funzioni, ma prima non hai degli sticker da creare?
